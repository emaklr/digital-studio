# Abeeb Digital Studio

International digital solutions studio offering websites, web applications, AI integrations and business automation.

## Direction

- Visual identity: dark premium with bold creative accents.
- Primary currency: USD starting prices.
- Sales model: productized service packages plus custom project enquiries.
- Booking: package selection, project intake and deposit checkout (payment provider to be configured before enabling live payments).

## Planned stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- PostgreSQL + Prisma for enquiries and bookings
- Resend for transactional email
- Payment provider selected after confirming supported business-country and settlement requirements

Initial website build in progress.
